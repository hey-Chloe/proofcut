# ProofCut claim boundary

## Confirmed locally

- A Python CLI accepts valid timestamped JSON or text transcripts.
- It deterministically creates topical segments with source utterance indices,
  timestamps and exact source quotes.
- Each segment contains hook, title, caption, SEO keywords and thumbnail brief.
- JSON and CSV evidence ledgers are written locally.
- A localhost-only browser interface accepts `.json` and `.txt`, runs the same
  Python pipeline as the CLI, displays source-linked segments and downloads JSON
  or CSV.
- The lexical risk gate flags unsupported numbers, configured absolute language
  and low source overlap.
- Six frozen self-authored fixtures are evaluated by the local eval command.
- Test and evaluation results may be stated only with the exact current receipt
  and manifest SHA.

## Not established

- No creator has used or preferred ProofCut.
- No editing-time or cost saving has been measured. Never claim a percentage.
- The risk gate is not a general factuality proof and may have false positives
  or false negatives outside the frozen probes.
- Estimated plain-text timestamps are not aligned to real audio or video.
- No external LLM quality, multilingual generalization, production throughput,
  accessibility or security assessment has been completed.
- The local browser demo is not a public deployment and has not been tested with
  real creator media or user transcripts.
- No public deployment, public repository, hackathon submission, finalist
  result, prize or winner result exists.

## Allowed one-line description

> Built and locally tested a deterministic transcript-to-content-pack MVP with
> source-linked JSON/CSV evidence ledgers and a lexical unsupported-claim gate
> on six self-authored fixtures.

Do not shorten that into “AI fact checker,” “production-ready,” “saves time,”
“submitted,” “award-winning” or similar claims without new evidence.
